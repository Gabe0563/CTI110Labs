02File basics

Creating, saving & naming documents

A new document starts blank until you save it. Ctrl+S saves your work; the first time you do it, Word asks where to save and what to name the file. After that, the same shortcut saves changes to the same file without asking again.

Save updates the existing file. Save As (F12) creates a new copy under a different name or location — use it when you want to keep the original untouched.

Word autosaves to a temporary file every few minutes, but that's not a substitute for saving on purpose. Get in the habit of Ctrl+S every few minutes.

Styles & document structure

Instead of manually bolding and enlarging every heading, use built-in Styles. They keep formatting consistent and let Word build a table of contents automatically. Click into a line, then pick a style.

Documents built with Heading styles can generate an automatic table of contents (References tab → Table of Contents) — one more reason to use styles instead of manual formatting.

07Try it

Page setup & printing

Page setup controls live on the Layout tab: margins, orientation, and size. Drag the slider or flip orientation to see how it reshapes the page.

When you're ready to print, Ctrl+P opens Print settings — or use File → Export → Create PDF/XPS to save a shareable, non-editable copy.
