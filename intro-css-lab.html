Objective Connect an external stylesheet, then follow the design spec below to style four parts of the page.

Work from this spec the way you would a real client brief. Everything below is checkable, so if you follow it, your score will reflect that.

Use pixels for every size in this assignment (not em, rem, or percentages), so your sizes are easy to verify.

1. Link the Stylesheet

This page isn't connected to its stylesheet yet. Add whatever's needed in the <head> of the HTML to link the two files together so the CSS actually applies.

2. Intro Paragraph

Give the welcome paragraph a different, more readable font than the browser default — Georgia, Verdana, Tahoma, Trebuchet MS, Courier New, and Times New Roman are all good choices. Set its size to either 16 or 18 pixels.

3. Title Heading

Style the shop's name at the top of the page: give it a distinct color (navy, steelblue, maroon, forestgreen, saddlebrown, and midnightblue are all good choices — a hex code works too), center it horizontally, and size it somewhere between 28 and 40 pixels so it reads as a clear heading.

4. Menu List

The menu items currently show as a plain bulleted list. Remove the bullets, and add at least a little breathing room (8 pixels or more) so the items aren't crammed together.

5. Navigation Panel

Give the navigation bar a background color (use the same color options as the heading, or any hex code), and add at least 8 pixels of padding around its contents so the links aren't touching the edges.

Task Checklist

  • <link>Stylesheet linked in <head>
  • font-family.intro-text uses an approved font
  • font-size.intro-text is 16px or 18px
  • color#page-title uses an approved color
  • text-align#page-title is centered
  • font-size#page-title is 28–40px
  • list-style-type.menu-list bullets removed
  • padding/margin.menu-list has spacing added
  • background-color.site-nav uses an approved color
  • padding.site-nav has padding added

Tip: the <head> is where a page connects to an outside stylesheet — think about what tag makes that connection.
